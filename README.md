# 🎮 Rebound

*A 2D platformer built with Python and Pygame.*

> **The top is waiting. Can you reach it?**

## Gameplay

Your goal is simple: **keep climbing.**

Jump across platforms, use your double jump to reach difficult spots, and keep moving upward. Miss a platform or hit an obstacle, and it's game over.

## Features

- Double-jump mechanics
- Moving obstacles
- Animated player sprites
- Scrolling camera
- Procedurally generated platforms
- Custom sound effects

## Controls

| Input | Action |
|:---:|---|
| `A` / `←` | Move left |
| `D` / `→` | Move right |
| `W` / `↑` | Jump |
| `W` / `↑` (midair) | Double jump |

## 🛠️ Built With

- **Python**
- **Pygame**
